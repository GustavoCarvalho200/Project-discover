# DevLinks

Página pessoal de links desenvolvida com HTML, CSS e JavaScript. O projeto reúne redes sociais e outros destinos em uma interface responsiva, com alternância entre temas claro e escuro.

## Recursos

- Perfil com foto e identificação do usuário.
- Atalhos para redes sociais.
- Botões para links personalizados.
- Alternância entre os temas claro e escuro, com estado acessível por atributos ARIA.
- Layout responsivo com efeitos visuais em transparência.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Ionicons

## Executar localmente

Abra o arquivo `porti.html` diretamente no navegador ou use a extensão Live Server do Visual Studio Code para visualizar a página durante o desenvolvimento.

## Personalização

- Edite o conteúdo, a foto de perfil e os destinos dos links em `porti.html`.
- Ajuste cores, tipografia e layout em `port.css`.
- Altere o comportamento da alternância de tema em `port.js`.
